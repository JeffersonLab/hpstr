Detailed Description

Closure test of the truth-link chain, off by default.

The chain that feeds PreselectAndCategorize2021's truth_ele_id is

tracker hit -> getRawHits() -> mcPartRelLcio_ -> SimTrackerHit -> getMCParticle()->id() -> Track::addMcpHit() -> plurality -> lookup in the hpstr MCParticle collection

and every stage can drop the link while looking identical downstream: hasTruthMatch() returns false whether the relation was missing, the MCParticle pointer was null, the id resolves to nothing in the stored MCParticle collection, or the plurality lands on a non-e+-. These counters separate those cases and check that what LCIO offered is exactly what ended up on the hpstr Track.
