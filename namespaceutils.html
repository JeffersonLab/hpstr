◆ getTruthPDG()

int getTruthPDG ( Track & trk,
const std::vector< MCParticle * > * mcParticles,
bool debug = false )
inline

Get the PDG code of the truth particle best matching this track.

Finds the MC particle with the most hits on the track using two methods:

  1. getMcpHits() from Track (populated by VertexProcessor)
  2. getSvtHits() and getMCPartIDs() from TrackerHits (fallback)
Parameters
trkThe track to match
mcParticlesPointer to the MC particle collection
debugEnable debug output
Returns
PDG code of best-matching particle, or 0 if no match found
