Detailed Description

template<typename T>
struct EventBus::auto_clearable< T >

Whether an output of this type can be safely reset between events.

Scalars and std::vector reset to a well-defined empty state that owns nothing. Class types are deliberately excluded: the event classes reset via their ROOT Clear(), and some of those assume they own their contents – MCParticle::Clear() calls daughters_->Delete(). Because bus_.set() stores a shallow copy, that would delete objects still owned by the input collection and corrupt the event being processed.
