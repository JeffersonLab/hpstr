Detailed Description

Data momentum scale corrections for tracks: a run-by-run scale and, optionally, a mean correction. Either can be switched off by leaving its config empty.

Run-by-run scale (runScaleCfg): the "runScale" block of a FEE scale JSON, e.g. analysis/data/smearing/fee_scale_smearing_2021_3p74.json,

"runScale": { "default": {"top": k, "bot": k}, "runs": { "<run>": {"top": k, "bot": k, ...}, ... } }

With half = top if tanLambda > 0 else bot, px, py, pz are multiplied by k and omega divided by k; runs not in the table use runScale.default.

Mean correction (meanCorrCfg): a JSON in the TrackSmearingTool schema. It applies the same correction as TrackSmearingTool's data mode, omega' = omega + (mu_mc - mu_data), with the momentum scaled by omega / omega'. With meanCorrVariable empty the unbinned "omegaSmearing" mu_data/mu_mc are used; with "phi0", "tanLambda" or "nHits" the means come from "omegaSmearing_binned_<variable>" (falling back to the unbinned ones if that table has no means), looked up as TrackSmearingTool does.

The run scale is applied first, then the mean correction. The tool is meant for data only – the caller decides when to use it. Smearing is not touched.
