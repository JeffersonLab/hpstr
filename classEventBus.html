◆ clear_outputs()

void clear_outputs ( )
inline

Reset the resettable output passengers to their default state.

Call this at the start of each event. Branches that are only set under some condition (e.g. the truth branches, which need a truth match to be computed) would otherwise still be holding the value from the last event that did set them, and that stale value gets written into the tree.

Only outputs are reset – input passengers are attached to the input TTree and are refilled by ROOT on each entry, so clearing them here would throw away the event we are about to process. Class-typed outputs are also left alone; see auto_clearable above. Consumers of a conditionally-set class-typed branch should gate on a companion scalar (which is reset) rather than trusting the object itself.
